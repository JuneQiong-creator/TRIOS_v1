# Available historical source, not a complete runnable archive

Sources are bound by `../provenance/SOURCE_BINDINGS.csv`: original full-file SHA, public transformed SHA, and transformation are distinct. Host absolute paths were redacted; named computational functions exported into `src/trios_release` are additionally checked by text hashes. An original hash never certifies the transformed whole file. Current plotting scripts are separately adapted for replay.

Public source locators may use naming aliases. Original source SHA-256 values are retained; SOURCE_BINDINGS.csv distinguishes original bytes from path/name-adapted public bytes. These aliases do not recover absent historical inputs.

These files are provided for reading the historical generation/analysis logic and version bindings. Original instruction PDFs, recovered fit-state banks, original workbook containers, binary checkpoints and many archived dynamic-import dependencies are intentionally not part of this small release. Full producer mains are NOT validated commands and may require missing inputs. Do not infer full recomputation from their presence. Use the safe commands in the top-level README instead.

The actual historical HB AB compares binary64 SSE tuples. The actual current CCLE AB uses its already-bound guarded exact-dyadic shortlist helper. The domain/resolution simulation uses its own hash-bound historical AB. The later helper is not substituted into older experiments. Historical E4/E5 dependency snapshots and the contemporaneous external stress-generator snapshot remain unresolved; available present source is not described as recovered historical code.
