# Figure replay contract

Purpose: replay existing figures and inspect their source evidence; no new scientific inference or redesign. Figure 1 is the unchanged TikZ method architecture. Figures 2/3 use HB domain/resolution/stratification and ORIGINAL5 benchmark extracts. Figure 4 uses current exact-log post-fit domain/resolution summaries and current Q50 81-method truth recovery; Figures 5/6 use accepted prospective and structural-stress source tables. Figures 7/8 use full-source transported/molecular and current fixed-representation comparison summaries. Each quantitative render function is preserved from the accepted Python code; only data loading/output paths are adapted.

Frozen point estimates, stored intervals, cohorts, weights, denominators, missing values, axis/layout design and rendering sizes are unchanged. No simulation, fitting, domain reselection, classifier, LOO, new random resampling, bootstrap or test is run by replay. A Figure 1 replay additionally needs a local TeX installation with article/geometry/TikZ. Replayed font appearance can vary where proprietary Arial is unavailable; no font file is redistributed. Public result/source index and manifests record exact original/public SHA values.
