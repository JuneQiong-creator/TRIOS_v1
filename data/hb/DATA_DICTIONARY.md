# De-identified HB-PDO response data

The authors authorize public release of these previously collected de-identified drug-response measurements and necessary analytical fields. No identity mapping, raw clinical record, workbook name, sheet or source-row locator is supplied. No new patient or wet-laboratory study was performed for this paper. Original approval: SCMCIRB-K2023075-1; written consent from legal guardians. Restricted associated material requests: Ping He, heping@bnbu.edu.cn. Licence remains to be confirmed; public release permission does not specify a reuse licence.

`hb_pdo_drug_response.csv`: 1,832 source dose/replicate rows, 114 PDO–regimen profiles. `PDO_ID` is a de-identified analysis-profile code, not a publicly linked patient identity. `regimen` codes: 5FU, CARBO, CARBO_A, CDDP, CDDP_A, ETO; A suffix denotes combination with doxorubicin. `dose_uM` uses the source regimen concentration coordinate; zero is an actual measured condition. `replicate_ID` is the source technical replicate index 1–3. `response_inhibition` and `viability_ratio` are dimensionless recorded measurements; do not clip or rescale them. `QC_status` and `dose_unit` retain source analytical metadata.

`source_to_eligible_membership.csv` supplies the original inclusion flag and exclusion code. Apply that flag by profile code, without treating profiles as distinct patients. The eligible analysis retains 113 profiles and 1,817 rows. The source-to-eligible mapping changes no source measurement. Included flags are stored as their original values; missing CSV fields remain empty, not zero.

`frozen_fit_parameters.csv` contains per-profile/model parameter names, unconstrained and natural-scale values and chosen start IDs. `frozen_fit_status.csv` retains recorded validity/failure, GCV, selected lambda, effective degrees of freedom and fit diagnostics. These are previously frozen fit outputs, not new fits. The small example reads the stored spline state; it never fits a curve. Do not reinterpret spline basis count as assay dose count.

The relationship to the earlier HB-PDO study is reuse of the same de-identified measurement resource. This release uses TRIOS-specific eligibility, scores and strata, not another study's classification labels. Column projection is documented by the original-file hash and release-file hash in `../../provenance/SOURCE_BINDINGS.csv`.
