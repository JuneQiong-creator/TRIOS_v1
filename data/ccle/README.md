# Actual legacy CCLE inputs — acquisition required

Raw response, sample metadata, mutation and panel files are NOT mirrored. Exact names, dated versions and hashes are in [REQUIRED_LEGACY_INPUTS.csv](REQUIRED_LEGACY_INPUTS.csv). The derived 69-cohort ZIP is an analysis artifact, not a distinct original-provider data release. It is also not mirrored; its hash is a locator for the original locally bound artifact.

Official routes: [CCLE datasets](https://sites.broadinstitute.org/ccle/datasets), [legacy CCLE browse data](https://portals.broadinstitute.org/ccle/data/browseData), [DepMap download portal](https://depmap.org/portal/download/all/). Search/request the exact dated filenames. Do not substitute a modern DepMap release or a similarly named reformatted file; verify SHA before analysis. A working direct public download for every legacy file was not verified during publication. Contact the official provider if the legacy archive is not offered. No silent fallback is provided.

The current DepMap terms endpoint presented an anti-bot verification page during this check; an applicable raw-file redistribution licence for these specific 2012/2015 inputs was not confirmed. Generic newer-release CC-BY notices were not treated as permission for these legacy files. Broad's [general terms](https://www.broadinstitute.org/contact-us/terms-and-conditions) do not establish permission to mirror these exact datasets. Accordingly, original third-party files and raw seven-cohort response derivatives are omitted. Their terms remain those of the providers.

`locked_subset_membership.csv` is the analysis-specific membership registry (7 datasets × 100 subsets × 18 members), not raw pharmacological measurements. Figure source tables and method-level statistics are study-derived outputs. Eight positive measured concentrations are 0.0025, 0.008, 0.025, 0.08, 0.25, 0.8, 2.53, 8 μM. There is no measured zero-dose CCLE condition. CCLE AUC uses [0.0025,8] μM, never HB AUC250. Reference labels are analytical assignments, not biological truth.
